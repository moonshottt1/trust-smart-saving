# TrustSmartSaving.com

Static brand-presence site for trustsmartsaving.com.

## Local dev
Open `index.html` in your browser, or run a simple local server:

```bash
python -m http.server 8080
```

## Deploy
Push to GitHub → connect Cloudflare Pages → set framework preset to "None", build command blank, output directory `/`. Add custom domains `trustsmartsaving.com` and `www.trustsmartsaving.com` in Cloudflare Pages.
